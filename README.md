# Analyse-Bati-Modus-Aedificandi

# Analyse de données spatiales et du bâti marseillais

Ce dépôt présente les travaux réalisés lors de mon stage de Master 1 en tant que Data Analyst au sein de l'entreprise **Modus Aedificandi**, à Marseille (Avril 2025 - Août 2025).

## Contexte du projet
Cette mission s'inscrivait dans le cadre d'un projet d'envergure mené en collaboration avec l'Union Européenne[cite: 1]. 
L'objectif final était de concevoir un modèle d'analyse urbaine qui soit reproductible pour d'autres grandes villes européennes[cite: 1].

## Mes Missions et Réalisations
* **Gestion des données :** J'ai pris en charge l'analyse et le traitement de très grandes bases de données concentrées sur le bâti marseillais[cite: 1].
* **Restitution :** J'ai assuré la visualisation de ces données urbaines pour les rendre lisibles et exploitables par les équipes[cite: 1].

## Outils & Compétences mobilisés
* **SIG et données spatiales :** Utilisation de logiciels spécialisés comme QGIS[cite: 1].
* **Traitement de bases de données :** Nettoyage et structuration via EXCEL ou en langage SQL sur QGIS[cite: 1].
